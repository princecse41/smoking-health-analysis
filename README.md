# smoking-health-analysis

🚬 Smoking Health Risk Analysis Dashboard
📌 Project Overview

The Smoking Health Risk Analysis Dashboard is an interactive Power BI project designed to analyze the impact of smoking on human health. The dashboard helps identify how smoking, alcohol consumption, BMI, physical activity, and other health indicators influence the risk of developing diseases related to the heart, lungs, kidneys and liver.

This project transforms raw healthcare data into meaningful insights through interactive visualizations, KPIs, filters, and DAX calculations. It is designed to support data-driven decision-making and demonstrate practical data analytics skills.

🎯 Project Objectives
Analyze the relationship between smoking habits and health risks.
Identify high-risk individuals based on multiple health factors.
Compare healthy and damaged organ conditions.
Understand how age, BMI, physical activity, sleep, and alcohol consumption affect health.
Build an interactive dashboard for healthcare data analysis.

🛠️ Tools & Technologies
Power BI Desktop
Power Query
DAX (Data Analysis Expressions)
Microsoft Excel

💡 Key Insights
Smoking significantly increases the risk of heart, lung, kidney, liver, and brain-related diseases.
Higher BMI is associated with increased health risks.
Physical activity contributes to better overall health scores.
Older age groups show higher disease prevalence.
Smoking combined with alcohol consumption results in higher health risks.

🚀 How to Use
Clone this repository.
Open the .pbix file in Power BI Desktop.
Load the dataset if prompted.
Interact with the slicers and visuals to explore the data.
Switch between the Healthy Analysis and Damage Analysis pages to gain different perspectives.
